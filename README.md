<h4>🧠 Mansik Santulan — Student Mental Health Score Predictor</h4>

A machine learning web application that predicts student mental health scores using lifestyle and stress-related inputs.

- Developed a **Random Forest Regression** model using **scikit-learn**.
- Processed inputs including sleep, social media use, study hours, physical activity, and stress levels.
- Integrated predictions through **FastAPI REST endpoints** with input validation.
- Built a responsive **HTML, CSS, and JavaScript** interface with score visualization.
- Used **Pandas and NumPy** for data processing.

<h4>💬 Emotion Predictor — Deep Learning-Based Text Emotion Analysis</h4>

An NLP application that classifies text into **sadness, joy, love, anger, fear, and surprise**.

- Developed a **BiGRU model** using **TensorFlow and Keras**.
- Implemented text preprocessing, tokenization, word embeddings, and sequence padding.
- Integrated the model with **FastAPI**, **Pydantic**, and **NumPy**.
- Returned predicted emotions, confidence scores, and emotion probabilities.
